Estimator assumptions, limitations & code

Assumptions added for this model: Each participating passenger brings exactly one identical bag requiring one space. Capacity is one shared pool of usable bag spaces. Bag demand is rounded to the nearest whole bag. All overflow is gate-checked. The gate-check percentage uses carry-on bags, not all passengers, as its denominator.

Limitations: No measured flight data or randomness is used. This is a scenario calculation, not a probability forecast. Different bag sizes, separate-bin gaps, boarding order, crew storage, airline procedures and baggage collection times are excluded. Changing boarding order alone cannot reduce overflow in this equal-size shared-pool model. The small simulation below explores why separate bins can behave differently.

const bags = Math.round(passengers * carryOnPercent / 100);
const gateChecked = Math.max(0, bags - capacity);
// With no bags, display N/A instead of dividing by zero.
const percent = bags === 0 ? null : gateChecked / bags * 100;

01 / THE OBSERVATION

A familiar boarding moment.

Overhead bins sometimes fill before everyone boards. Some passengers have to gate-check their carry-ons, which can mean waiting to collect them after landing.

02 / WHAT WE SIMPLIFIED

Rules for the small boarding demo.

We assume three 4-unit bins, one 1–3-unit bag per passenger, and a fixed boarding order. Bags cannot rotate or be rearranged. The separate-bin model uses the first bin with enough space.

03 / WHAT THIS LEAVES OUT

A model has its limits.

Real bags have three-dimensional shapes. This experiment leaves out seat locations, under-seat storage, staff decisions, and collection times. It explains a possibility, not what caused a particular flight’s problem.

Look under the hood Beginner-friendly JavaScript

Both models process exactly the same queue. Only the rule for finding space changes.

// Shared model: is there enough space in total?
if (bagSize <= sharedSpace) {
  sharedSpace -= bagSize;
} else {
  // Gate-check the bag.
}

// Separate model: find the first bin that can fit the bag.
const bin = bins.findIndex(space => space >= bagSize);
if (bin !== -1) {
  bins[bin] -= bagSize;
} else {
  // Gate-check the bag, even if small gaps remain.
}
